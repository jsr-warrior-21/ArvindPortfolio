## 🚀 Key Features & Highlights

- **High-Contrast Editorial Studio System**: High-contrast white background with rich black typography (*Plus Jakarta Sans*, *Inter*, *JetBrains Mono*) tailored after top-tier agency editorial designs.
- **Interactive 3D Constellation Mesh**: Custom HTML5 Canvas 3D node matrix background rendering 60fps parallax depth across all sections without heavy external dependencies.
- **Benchmarked Case Studies**:
  - **PulsePlay** ([Live Demo](https://pulseplays.netlify.app/)): Full-Stack Video Streaming platform tested for **250+ concurrent users** at **360+ req/sec throughput** with sub-200ms response times.
  - **Talkify** ([Live Demo](https://talkify-hpb2.onrender.com/)): Real-time Socket.IO chat app benchmarked via **Artillery for 500 concurrent virtual users across 10,000 requests** with 0% session failure rate.
- **Interactive Developer CLI Terminal**: Floating developer command-line modal (`Ctrl+K`) for keyboard-driven portfolio navigation.
- **Fail-Safe Contact System**: 1-click Direct Gmail Web Compose (`imarvind2121@gmail.com`) + WhatsApp launcher + Web3Forms fallback.

## 💻 Local Development Setup

```bash
# Clone the repository
git clone https://github.com/jsr-warrior-21/ArvindPortfolio.git

# Navigate into project directory
cd ArvindPortfolio

# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
